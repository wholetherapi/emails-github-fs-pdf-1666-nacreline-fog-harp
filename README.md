# Nacreline Fog Harp — Revision 4 Design Package

This repository keeps the original `nacreline-fog-harp` name but now implements the
**Revision 4** design, internal design ID `NFH-4`. The frame, tensioners and controller
are not compatible with NFH-2 or NFH-3 hardware. For Rev 2 builds use the NFH-2 sources
repository.

## Status
Released 2026-11-02. All Rev 4 fabrication files are final.
